## Orders spec: two failures fixed, 3/3 tests now pass

**What failed and why** (both bugs were in `app/index.html`, in the code that renders the orders table)

1. **"totals each order as price times quantity"** (r4). `total()` added up `item.price` and never used `quantity`. Order 1001 is 2 × $21.00, so the page showed `$21.00` instead of `$42.00`.
2. **"trims a delivery note to 40 characters"** (r5). `noteText()` returned the note as-is, so order 1003's long note appeared in full instead of being cut to 40 characters plus `…`.

**What I changed** (only `app/index.html`; no tests touched)
- Line 21: `sum + item.price` → `sum + item.price * item.quantity`
- Line 17: `return note;` → `return note.length > 40 ? note.slice(0, 40) + "…" : note;` (notes of 40 characters or fewer are unchanged)
